# Slide Studio AI 서버 시작하기

맥미니 한 대로 시작할 수 있습니다. 이 프로그램은 사용자의 초대 코드와 이용 한도를 확인하고 OpenAI에 요청을 전달합니다. GPT 추론은 OpenAI에서 실행하므로 맥미니에 AI 모델이나 GPU를 설치할 필요가 없습니다. 앱 사용자는 처음 한 번 초대 코드를 입력하고 **AI 보완하기**만 누릅니다.

| 실행할 곳 | 적합한 경우 | 운영할 때 필요한 것 |
| --- | --- | --- |
| 내 맥미니 | 소수 사용자와 먼저 사용해 보기 | 맥미니 전원·인터넷·서버 프로그램 유지, 잠자기 방지, 외부 HTTPS 주소 |
| 연구실 서버 | 여러 사람이 계속 사용하기 | 서버 사용 권한, Node.js 24 이상 또는 Docker, HTTPS 연결 |

현재는 서버 코드와 앱 연결 검사를 완료한 개발판입니다. 실제 API 키, OpenAI 프로젝트 지출 한도, 외부 HTTPS 주소는 아직 설정하지 않았습니다. 기본 설정의 장수 한도는 `0`이므로 실수로 실행해도 새 추론을 받지 않습니다.

## 1. OpenAI에서 월 $30 한도와 키 만들기

1. [OpenAI Platform](https://platform.openai.com/)에서 Slide Studio 전용 프로젝트를 만듭니다. 다른 서비스와 프로젝트를 나누면 이 앱에 쓴 비용을 확인하기 쉽습니다.
2. 해당 프로젝트의 **Settings → Limits → Spend → Edit spend limit**을 엽니다.
3. **Monthly spend limit**을 **30 USD**로 입력하고 **Enforce a hard limit**을 켠 뒤 저장합니다.
4. 같은 프로젝트에서 API 키를 만듭니다. 키는 아래의 맥미니 설정 파일에만 입력합니다.

알림만 설정하면 한도에 도달해도 요청이 계속됩니다. 지출 차단을 켜야 합니다. 한도 반영에는 지연이 있어 기록된 비용이 소폭 초과할 수 있습니다. 프로젝트에 결제 수단이나 사용 가능한 크레딧도 필요합니다. [공식 지출 한도 안내](https://developers.openai.com/api/docs/guides/spend-limits)

키는 설치 앱·초대 코드·GitHub·채팅에 넣지 않습니다. OpenAI도 앱 같은 클라이언트 코드에 키를 노출하지 않고 서버의 환경 변수에서 읽도록 안내합니다. [공식 인증 안내](https://developers.openai.com/api/reference/overview#authentication)

## 2. 맥미니에서 실행하기

운영하는 맥미니에만 Node.js 24 이상이 필요합니다. 일반 사용자는 Windows·Mac 설치 앱만 설치하면 됩니다. 현재 소스 폴더는 `/Users/jangwon/Projects/slideStudio`입니다.

1. Finder에서 `server/start-mac.command`를 두 번 클릭합니다. 처음 실행하면 비공개 설정 파일 **`server/.env`**를 만들고 텍스트 편집기로 엽니다.
2. 다음 항목을 설정하고 저장합니다. API 키는 `OPENAI_API_KEY=` 뒤에 붙입니다. 아래 장수는 소규모 테스트를 위한 예시입니다.

```dotenv
OPENAI_API_KEY=여기에_내_실제_API_키
OPENAI_MODEL=gpt-6.1-sol
OPENAI_REASONING_EFFORT=low
OPENAI_MAX_OUTPUT_TOKENS=12000
STUDIO_DAILY_PAGES=100
STUDIO_MONTHLY_PAGES=500
STUDIO_CONCURRENT=2
STUDIO_TIME_ZONE=Asia/Seoul
STUDIO_HOST=127.0.0.1
PORT=8787
```

3. `start-mac.command`를 다시 실행하고 터미널 창을 열어 둡니다. `inference enabled`가 나오면 서버가 요청을 받을 준비가 된 것입니다. 이 문구만으로 실제 API 키 권한이나 결제 상태가 검증된 것은 아닙니다.
4. 브라우저에서 `http://127.0.0.1:8787/health`를 열어 `configured: true`를 확인합니다. 같은 맥미니에서 초대 코드를 만들면 로컬 연결을 시험할 수 있습니다.

기본 모델은 이미지 입력과 구조화된 JSON 응답을 지원하는 [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol)입니다. 모델은 운영자가 서버에서 지정하므로 사용자는 모델을 고를 필요가 없습니다. 처음에는 소량의 강의로 결과·비용·속도를 확인하세요. 추론 품질은 실제 API로 검증해야 합니다.

이 서버에는 프로덕션 npm 패키지가 필요하지 않습니다. 터미널에서 실행하려면 저장소 루트에서 `npm run server:start`를 사용합니다. **Ctrl+C**로 중지합니다. `.env`를 수정하면 서버를 재시작합니다. macOS에서 서버가 계속 돌아가려면 잠자기를 방지하고 전원·인터넷·터미널 프로세스를 유지해야 합니다. 로그인 시 자동 실행은 아직 설정하지 않았습니다.

장수 한도는 **달러 예산과 별개**입니다. 전체 사용자가 합쳐 하루 100장, 한 달 500장까지만 새 요청을 받는 예시이며, $30으로 몇 장을 처리할 수 있다는 뜻은 아닙니다. 이미지는 크기, 음성 원문은 길이, 답변은 분량에 따라 비용이 달라집니다. 실제 비용은 OpenAI에서 확인합니다. 전체 장수 한도 중 하나라도 `0`이면 새 요청을 중단합니다. 일간·월간 장수는 한국 시각의 날짜·달을 기준으로 초기화됩니다.

## 3. 초대 코드를 발급하기

프로젝트 폴더에서 아래 명령을 실행합니다. 여기서 만든 코드는 같은 맥미니에서만 연결하는 로컬 시험용입니다.

```bash
cd /Users/jangwon/Projects/slideStudio
npm run server:admin -- invite --name "테스트 사용자" --endpoint http://127.0.0.1:8787 --daily 20 --monthly 200 --days 30
```

출력되는 `SS1.`로 시작하는 코드를 사용자에게 전달합니다. 사용자는 앱의 **AI 연결 설정**에 입력합니다. 코드는 서버 주소와 해당 사용자만의 접속 권한을 포함하고, OpenAI 키는 포함하지 않습니다. 초대 코드는 비밀번호처럼 취급하세요. 같은 코드를 여러 사람에게 공유하면 동일한 사용자 한도를 함께 소모합니다.

| 옵션 | 의미 |
| --- | --- |
| `--daily 20` | 이 사용자에게 하루 최대 20장 허용 |
| `--monthly 200` | 이 사용자에게 한 달 최대 200장 허용 |
| `--days 30` | 발급 후 30일 동안 연결 허용 |

기존 사용자 목록과 사용자 ID는 아래에서 확인합니다. 초대 코드 원문은 서버에 저장하지 않아 다시 조회할 수 없습니다.

```bash
npm run server:admin -- list
npm run server:admin -- revoke --id 사용자ID
```

`revoke`는 새 요청과 결과 조회를 막습니다. 이미 OpenAI로 보낸 추론은 계속될 수 있습니다. 코드를 분실하면 기존 코드를 폐기하고 새로 발급합니다. 앱의 **연결 해제**는 해당 기기의 연결 정보만 지우며, 서버의 코드 자체를 폐기하지 않습니다.

## 4. 다른 컴퓨터에서도 연결하기

외부 사용자는 `127.0.0.1`로 내 맥미니에 접속할 수 없습니다. **`https://`로 시작하는 고정된 외부 주소**를 맥미니의 `127.0.0.1:8787`로 연결해야 합니다. 연구실에서 관리하는 HTTPS 리버스 프록시나 인증서를 제공하는 터널을 사용할 수 있습니다. 현재 외부 주소·도메인·터널 계정은 연결하지 않았습니다.

외부 연결을 구성할 때의 조건은 다음과 같습니다.

- 별도 경로가 없는 HTTPS 주소 전체를 이 서버로 전달합니다. 예: `https://slides.example.org`.
- `Authorization` 헤더와 JSON 본문을 전달하고, 본문은 최대 16 MiB·응답 대기는 최소 150초를 허용합니다.
- 프록시의 자동 재시도를 끄고, 요청·응답 본문이나 인증 헤더를 로그에 남기지 않습니다.
- 기본 서버는 로컬에서만 수신합니다. 공용 HTTP 포트를 직접 열지 말고 HTTPS를 제공하는 계층을 앞에 둡니다.

연결 후 `https://실제서버주소/health`를 확인하고, 외부 주소로 새 초대 코드를 발급합니다.

```bash
npm run server:admin -- invite --name "사용자 이름" --endpoint https://실제서버주소 --daily 20 --monthly 200 --days 30
```

사용자는 이 코드만 입력하므로 주소를 직접 옮겨 적을 필요가 없습니다. 서버 주소가 바뀌면 기존 코드를 폐기하고 새 주소로 다시 발급합니다. 설정한 주소에서 실제 슬라이드 1장으로 보완·취소·이어쓰기를 확인한 뒤 앱을 공개 배포합니다.

## 연구실 서버에서 Docker로 실행하기

연구실 서버의 사용 권한과 HTTPS 제공 방법을 먼저 확인합니다. 저장소 루트에서 실행합니다. `.env`는 Docker 빌드 컨텍스트와 이미지에서 제외합니다.

```bash
docker build -f server/Dockerfile -t slide-studio-ai .
docker volume create slide-studio-ai-data
docker run -d --name slide-studio-ai --restart unless-stopped \
  --env-file server/.env \
  -e STUDIO_HOST=0.0.0.0 \
  -p 127.0.0.1:8787:8787 \
  -v slide-studio-ai-data:/data \
  slide-studio-ai
```

맥미니와 같은 API 프로젝트·환경 설정을 사용할 수 있습니다. SQLite 데이터 폴더 하나에는 **서버 한 인스턴스**만 실행합니다. 서버를 옮길 때는 중지 후 `server/data/` 전체를 복사하고, Docker에서는 `/data` 볼륨에 같은 파일을 넣습니다. `.env`도 별도로 옮기되 GitHub에 올리지 않습니다. 데이터베이스를 새로 만들면 사용자 코드와 장수 이력이 초기화됩니다.

## 취소·재시도와 데이터 보관

- 서버가 받아들인 슬라이드 수를 먼저 한도에서 차감합니다. 오류로 결과를 받지 못해도 이미 API 비용이 발생했을 수 있어 자동 환불하지 않습니다.
- 앱은 요청 ID를 자동 저장한 뒤 보냅니다. 같은 ID와 자료로 다시 요청하면 진행 중인 작업이나 저장된 결과를 이어받습니다. 새 추론을 만들지 않습니다.
- 앱에서 취소하면 연결을 멈춥니다. 서버에 이미 전달한 작업은 끝까지 실행해 결과를 보관할 수 있습니다. **취소가 API 비용을 취소한다는 뜻은 아닙니다.**
- 생성 결과는 요청 시작 후 24시간 동안 이어받을 수 있습니다. 만료된 결과는 요청 시·서버 시작 시·실행 중 매분 정리합니다. 서버가 중지되어 있으면 다음 실행 시 정리합니다.
- 만료되거나 서버 중단으로 결과를 확정하지 못한 요청은 자동으로 다시 실행하지 않습니다. 앱이 안내하고 사용자가 다시 시작할 때 새 요청으로 처리합니다.
- 요청 ID·자료 해시·상태·토큰 수·장수·사용자 이름·초대 코드 해시는 중복 처리 방지와 운영을 위해 데이터베이스에 보관합니다. 입력 이미지·원본 영상·MP3·음성 기록은 데이터베이스에 저장하지 않습니다. 생성된 노트에는 원문의 일부가 들어갈 수 있습니다.
- OpenAI 요청에는 `store:false`를 지정합니다. 이것이 OpenAI의 모든 별도 보관 정책을 없앤다는 의미는 아닙니다. 이 안내의 결과 정리 규칙은 Slide Studio 서버에 적용됩니다. 데이터베이스 파일과 백업은 운영자가 관리합니다.

실제 키 없이 검증하려면 저장소 루트에서 `npm test`, `npm run test:assistant`, `npm run test:transcript`를 실행합니다. 실제 로컬 HTTP·SQLite·암호화·앱 UI를 사용하고 모델 답변만 모의 응답으로 바꿉니다. 현재 검사는 실제 OpenAI 비용이나 클로바노트 업로드를 발생시키지 않습니다.
